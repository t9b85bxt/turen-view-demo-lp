# TUREN VIEW — デモ LP

株式会社トレンビュー（福島県郡山市／中古バスの売買・整備・リメイク）向けの
提案用デモランディングページです。静的サイト（HTML / CSS / JavaScript）。

## 構成

```
index.html        1ページ完結の LP
css/style.css     スタイル
js/main.js        ライズアニメーション・フォームの確認画面など
images/           セクションごとの画像（すべて「写真はイメージです」）
```

## ローカルで確認する

```bash
python -m http.server 8000
# → http://localhost:8000
```

## 公開（GitHub Pages）

Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/ (root)` に設定。

## 注記

- 提案用のデモです。お問い合わせフォームは送信を行いません（確認画面まで動作）。
- 掲載写真はイメージで、実在庫・施工実績ではありません。
- 「認証整備工場 東北整認第4-7481号」「設立2009年」など、記載事項は
  公式サイト（turenview.com）で確認できる範囲のみを使用しています。
